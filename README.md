Mybank is a simple CLI banking system writen in Go.
It allows users to;
- open bank account
- deposit money
- withdraw 
- tranfer money to other user in the same platform.


the aim of this project is to learn the go basics and later on the complexities of data bases and apis as the project is projected to scale from simple into a real banking system in future.
this is the structure for the simple application.
